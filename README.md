# Job Navigator

##  Project Description

Job Navigator is a web application developed to help users find and explore job opportunities. The project provides different features for users and employers to manage job-related information.
The project was developed using Django and includes features such as job listings, user profiles, and job-related information.

##  Features

* User registration and login
* User profiles
* Job listings
* Job search
* Job application features
* Employer and job seeker profiles
* Job-related information management

## Technologies Used

* Python
* Django
* HTML
* CSS
* JavaScript
* SQLite
* Git & GitHub




## Conclusion

Job Navigator is a project developed to provide a simple platform for exploring job opportunities and managing job-related information. The project helped us understand Django, database handling, user profiles, and web application development.
